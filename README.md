# Ordinário News

Site do perfil Ordinário News, de Maracanaú, Ceará. Funciona sem servidor e sem custo de hospedagem.

- `index.html`: o site
- `content.json`: vídeos, indicações, segmentos, eventos, notícias, parceiros e redes
- `images/`: as imagens enviadas pelo editor

## Colocar no ar

1. Crie um repositório público no GitHub e envie o conteúdo desta pasta para a branch `main`.
2. No repositório, abra **Settings > Pages**. Em **Source**, escolha **Deploy from a branch**, depois `main` e `/ (root)`.
3. Em cerca de 1 minuto, o site abre em `https://usuario.github.io/nome-do-repositorio/`.

Domínio próprio é opcional e pode ser colocado depois: informe-o em **Custom domain**, ative **Enforce HTTPS** quando a opção liberar e, no registro.br, aponte o domínio para o GitHub Pages seguindo a [documentação do GitHub](https://docs.github.com/pt/pages/configuring-a-custom-domain-for-your-github-pages-site).

## Atualizar o conteúdo

1. Em **GitHub > Settings > Developer settings > Fine-grained tokens**, crie um código de acesso só para este repositório, com **Contents: Read and write**.
2. Abra o site com `#editar` no fim do endereço. Exemplo: `https://usuario.github.io/nome-do-repositorio/#editar`.
3. Informe o repositório (`usuario/nome`) e o código. Isso é feito uma vez por aparelho.
4. Edite e clique em **Publicar no site**. A mudança aparece em cerca de 1 minuto.

O código de acesso permite alterar o repositório: não o compartilhe e use **Sair deste aparelho** em aparelhos que não sejam seus. Cada publicação fica no histórico do GitHub, o que permite voltar a uma versão anterior.
